# APP 页面设计规范

## 概述

本文档定义了一套完整的 APP 页面设计系统，包含登录、注册、主页、AI 聊天、日程管理、企业资讯、个人中心等核心页面。设计风格为科技时尚，支持深色/亮色双主题，适配移动端和桌面端。

## 设计系统基础

### 颜色方案

#### 深色主题（主主题）

- **背景色**：`#0a0a0f`（深邃黑）→ `#1a1a2e`（深空蓝）
- **卡片背景**：`#16171d` 带毛玻璃效果
- **主色调**：紫蓝渐变 `#7c3aed` → `#3b82f6`
- **强调色**：霓虹紫 `#a855f7`、电光蓝 `#06b6d4`
- **文字色**：`#ffffff`（主文字）、`#a1a1aa`（次要文字）

#### 亮色主题

- **背景色**：`#fafafa`（纯净白）
- **卡片背景**：`#ffffff` 带轻微阴影
- **主色调**：同深色主题
- **文字色**：`#18181b`（主文字）、`#71717a`（次要文字）

### 设计特效

#### 玻璃态（Glassmorphism）

```css
.glass {
  backdrop-blur: blur(20px);
  background: rgba(255, 255, 255, 0.05); /* 深色 */
  background: rgba(0, 0, 0, 0.05); /* 亮色 */
  border: 1px solid rgba(255, 255, 255, 0.1);
}
```

#### 渐变效果

- 主按钮：线性渐变 `from-violet-600 to-blue-600`
- 背景装饰：径向渐变光晕
- 卡片悬停：渐变边框动画

#### 微交互

- 按钮悬停：轻微上浮 + 光晕扩散
- 卡片进入：淡入 + 轻微缩放
- 页面切换：滑动 + 透明度渐变

### 字体系统

- **主字体**：Geist Variable
- **标题**：`font-semibold` 或 `font-bold`
- **正文**：`font-normal`
- **辅助文字**：`font-light`

### 间距与圆角

- **间距**：基于 4px 网格（4, 8, 12, 16, 24, 32, 48）
- **圆角**：
  - 小组件：`rounded-lg`（8px）
  - 卡片：`rounded-xl`（12px）
  - 大容器：`rounded-2xl`（16px）
  - 按钮：`rounded-full`（完全圆角）

## 页面布局与导航结构

### 整体布局架构

#### 桌面端（≥1024px）

```
┌─────────────────────────────────────────────┐
│  顶部导航栏（Logo + 搜索 + 用户信息）        │
├────────┬────────────────────────────────────┤
│        │                                    │
│  侧边栏 │         主内容区域                 │
│  导航   │                                    │
│        │                                    │
└────────┴────────────────────────────────────┘
```

#### 移动端（<1024px）

```
┌─────────────────────┐
│  顶部栏（Logo+菜单） │
├─────────────────────┤
│                     │
│    主内容区域        │
│                     │
├─────────────────────┤
│  底部 Tab 导航栏     │
└─────────────────────┘
```

### 导航结构

**主导航项**（5个核心页面）：

1. **首页**（Home）
   - 图标：`Home`
   - 路径：`/`
   - 描述：综合主页，数据仪表盘 + 应用中心

2. **AI 聊天**（AI Chat）
   - 图标：`MessageSquare`
   - 路径：`/ai-chat`
   - 描述：多角色 AI 平台

3. **日程**（Schedule）
   - 图标：`Calendar`
   - 路径：`/schedule`
   - 描述：个人日程管理

4. **资讯**（Info）
   - 图标：`Globe`
   - 路径：`/info`
   - 描述：企业信息展示平台

5. **我的**（Profile）
   - 图标：`User`
   - 路径：`/profile`
   - 描述：个人中心、设置、系统管理入口

### 页面过渡动画

- **进入**：`fade-in` + `slide-up`（200ms）
- **退出**：`fade-out`（150ms）
- **共享元素**：使用 `layoutId` 实现卡片到详情的动画

## 动画系统

### 页面过渡

```css
/* 页面进入 */
@keyframes page-enter {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* 页面退出 */
@keyframes page-exit {
  from {
    opacity: 1;
  }
  to {
    opacity: 0;
  }
}
```

### 组件动画

1. **卡片进入**：`fade-in` + `scale-up`（300ms）
2. **按钮悬停**：`scale(1.02)` + 光晕扩散
3. **列表项进入**：依次淡入（stagger 50ms）
4. **模态框**：`scale(0.95)` → `scale(1)` + 淡入

### 加载动画

1. **骨架屏**：卡片/列表占位
2. **旋转加载**：Logo 旋转
3. **进度条**：顶部渐变进度条

- **CSS 框架**：Tailwind CSS v4
- **CSS 变量**：定义在 `src/index.css`
- **类名合并**：`cn()` 工具函数

### 状态管理

- **本地存储**：localStorage 持久化

### 路由系统

- **路由库**：React Router v7
